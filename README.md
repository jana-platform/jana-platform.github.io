# جَنى — لتثمير البحث العلمي

منصة ذكية تحوّل أبحاث الدراسات العليا إلى مخرجات تطبيقية تخدم المجتمع.

🌐 https://jana-platform.github.io

> نسخة تجريبية.

## مكونات المنصة
- **الصفحات** (هذا المستودع): HTML/CSS/JS بسيطة تُعرض عبر GitHub Pages.
- **Supabase**: الحسابات وقاعدة البيانات وتخزين الأبحاث مؤقتاً.
- **supabase/functions/generate**: تقرأ البحث عبر Gemini وتكتب المخرجات ثم تحذف الملف.
- **supabase/functions/delete-account**: الحذف النهائي للحساب.
