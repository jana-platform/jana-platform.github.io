المخرجات المتاحة

اختر منتجاً واحداً أو أكثر، أو الأربعة في نفس المرة.

📄

موجز سياسات

ورقة مختصرة لصنّاع القرار: المشكلة، أهم النتائج، وتوصيات عملية مع الجهة المعنية بكل توصية.

🖼️

ملصق علمي

ملخص بصري منظّم لأهداف البحث ومنهجيته ونتائجه، جاهز للعرض في المؤتمرات والطباعة.

💬

محتوى سوشيال ميديا

سلسلة تغريدات، ومنشور LinkedIn، ونص إنستقرام بلغة مبسطة تصل للمجتمع.

🎓

حقيبة تدريبية

برنامج تدريبي متكامل بجلسات وأنشطة وأساليب تقييم، موجّه للفئة التي تحددها.

قريباً: دورة · كتاب مبسّط · كتيّب · مطوية · مبادرة مجتمعية

من البحث إلى الجهة التي تحتاجه

ربط في الاتجاهين: الباحث يرفع رسالته، والجهات تسجّل احتياجاتها، وجَنى تطابق بينهما.

🎯

تقدير قابلية التطبيق

درجة من 5 لكل رسالة وفق خمسة معايير: وضوح التوصيات، وإمكانية التنفيذ، وحاجة المجتمع، والموارد المطلوبة، وجاهزية المستفيدين.

🌱

الأثر المتوقع

مستوى الأثر إذا طُبّق البحث، والفئات المستفيدة، ومداه الزمني، ومؤشرات قابلة للقياس لمتابعته، مع شروط النجاح والمخاطر.

🧩

مطابقة مع احتياجات الجهات

الجهات تسجّل التحديات التي تبحث لها عن حلول، والذكاء الاصطناعي يطابق كل رسالة معها بدرجة تطابق وسبب واضح.

هل تمثّل جهة؟

سجّل احتياج جهتك مجاناً وبدون حساب، وتصلك الأبحاث المطابقة عن طريق الباحثين أنفسهم.

سجّل احتياج جهتكتصفّح الاحتياجاتدليل الجهات (60+)

التقنيات المستخدمة

شفافية كاملة: هذه التقنيات والنماذج التي تعمل بها جَنى فعلياً.

🤖 Google Gemini API

نموذج لغوي كبير متعدد الوسائط يقرأ ملف PDF مباشرة ويكتب المخرجات والتقييم بصيغة JSON منظّمة. النموذج الأساسي gemini-3.5-flash-lite والاحتياطي gemini-3.8-flash، ويُسجَّل اسم النموذج الفعلي مع كل مخرج.

🧩 المطابقة والتقييم

تقييم آلي بنموذج Gemini نفسه وفق معايير محددة مسبقاً، مع تصفية أولية للاحتياجات حسب القطاع ثم مقارنة دلالية تعطي درجة تطابق (0–100) وسبباً مكتوباً.

🗄️ Supabase

قاعدة بيانات PostgreSQL مع سياسات أمان على مستوى الصف (RLS)، وتسجيل دخول آمن، وتخزين مؤقت خاص للملفات، ودوال خادم Edge Functions بلغة TypeScript على Deno.

🔎 التحقق من الملكية

مطابقة اسم الباحث مع أسماء مؤلفي البحث بواسطة Gemini، والاستعانة بقاعدة Crossref API العامة عند إدخال رقم DOI.

🌐 الواجهة والاستضافة

صفحات HTML وCSS وJavaScript خفيفة باتجاه عربي كامل، مستضافة على GitHub Pages، بخطَّي IBM Plex Sans Arabic وحيّاكم.
